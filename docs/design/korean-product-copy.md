# 앎 제품 문구 기준

사용자가 지금 볼 수 있는 내용과 할 수 있는 일을 먼저 쓴다. 감정을 대신 말하거나 기능보다 큰 약속을 하지 않는다. 설명은 짧은 해요체, 제목은 구체적인 명사, 버튼은 실제 행동으로 쓴다.

## 용어

| 대상 | 화면에서 쓰는 말 |
| --- | --- |
| 업로드할 문서 | 결과지 |
| 체험용 문서 | 예시 PDF / 예시 결과지 |
| 추출 후보 | 결과지에서 읽은 값 / 확인 전 항목 |
| 사용자가 확인해 저장한 내용 | 기록 / 검사값 |
| provenance | 출처 |
| revision history | 수정 내역 |
| 연구 프로젝트별 동의 | 연구별 동의 |
| 문서 처리 상태 | 지금 실제로 진행 중인 일을 설명하는 문장 |

## 이번에 바꾼 예

| 이전 | 변경 |
| --- | --- |
| 나를 알아가는 기록, 한곳에서. | 검사 결과 모아보기 |
| 첫 결과지부터 차근차근. | 결과지를 추가해 주세요 |
| 궁금했던 것, 잊지 않도록. | 진료 때 물어볼 질문 |
| 기록으로 만든 고정 질문 | 검사 기록에 대한 질문 |
| 적대적 문서 격리 구역 | 검사용 임시 보관 |
| 출처와 버전 보기 | 출처와 수정 내역 보기 |
| 삭제 요청 검토 | 전체 삭제하기 |

## 행동과 제한

- 오류에는 발생한 일과 다음 행동을 쓴다. 확인하지 못한 원인이나 저장 여부를 추측하지 않는다.
- 처리 상태는 서버가 보고한 단계만 말한다. 실제 상태 코드는 이름이 붙은 상세 정보에 유지한다.
- 체험에서는 등록된 예시 PDF만 허용하며 실제 결과지는 올릴 수 없다고 선택 화면에서 밝힌다.
- PDF 텍스트 추출과 사진·스캔 인식을 구분한다. 사용자가 원문을 확인하기 전에는 기록으로 저장하지 않는다.
- 내보내기 파일과 기존 기록을 구분한다. 파일을 내려받아도 기존 기록은 남는다.
- 삭제 확인에는 삭제 대상, 복구 불가, 체험 종료를 함께 쓴다.
- 연구 동의는 선택 사항이며 현재는 동의 내역만 저장한다. 실제 연구 참여에는 별도 동의가 필요하다.
- 외부 연결, 실제 정보 조회, 검사값 해석처럼 제공하지 않는 기능은 제공한다고 쓰지 않는다.

적용 범위: 홈, 결과지 추가·처리·확인, 기록 목록, 나의 데이터, 측정 이력, 진료 준비, 데이터 관리, 외부 서비스 연결, 공공정보 예시, 공통 오류와 접근성 이름. 회귀 검사는 `plain-product-copy.test.ts`와 `korean-ux-copy.test.ts`에서 수행한다.
