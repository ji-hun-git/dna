## Specific problems with the previous pass

Uniform cards and blue controls did not establish a product identity. A decorative black trajectory consumed the strongest visual position. An invented age/gender profile displaced useful work. Dense disclaimers and repeated labels competed with the actual record action. Navigation was consistent but felt attached to unrelated page compositions.

## Chosen direction

A quiet personal record book: warm-white canvas, charcoal type, olive used for actions and a single visit-preparation surface. Thin separators structure record rows; meaningful content supplies the visual interest. Original typographic 앎 wordmark, a fixed desktop rail, and four mobile destinations hold the product together. The signed-out page demonstrates the ledger with existing labelled examples. The authenticated home uses only confirmed server records and honest zero states.

## Deliberately excluded

No health score, fabricated trend, floating decoration, gradient hero, stock wellness photograph, or repeated bento-card layout. Source images were viewed for reference only; no third-party product image or brand asset is bundled. Legacy trajectory components remain available to isolated tests/concepts, but are no longer the live home.

## Review criteria

Compare entry, empty and populated home, data overview, records, history, preparation, and data management at desktop and mobile sizes. Primary actions remain at least 44px; navigation keeps the existing 48px desktop / 56px mobile test thresholds. Verify the original upload, confirmation, evidence, export and deletion workflow. Passing tests proves functional checks, not that the user has approved the visual direction.
