**Last updated:** 2026-08-30
**Operating rule:** research changes the product only after a claim is sourced, bounded, benchmarked where applicable, and translated into a testable engineering decision.

## Loop

`Question → primary evidence → claim ledger → bounded experiment → implementation → red-team/release checks → measured update`

Unknowns stay visible. A vendor statement stays a vendor statement. A synthetic benchmark stays synthetic. No assistant or model may promote a claim or medical fact by rhetoric.
