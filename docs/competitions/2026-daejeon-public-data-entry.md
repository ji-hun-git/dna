# 2026년도 공공데이터 활용 공모전 준비안

**상태:** 제품·아이디어 초안 준비 중. 참가자격 확인 전에는 제출팀을 구성했거나 접수가 가능하다고 주장하지 않는다.

## 가장 먼저 확인할 자격

공식 공고상 대상은 대전·세종 소재 대학의 대학생 또는 대학원생이며 1~4인 팀이다. 창업자 또는 실제 팀원이 이 요건을 충족하는지 증빙하기 전까지 상태는 `blocked-on-eligibility`다.

## 제안 출품

**분야:** 웹/앱 개발을 우선 검토하고, 자격·완성도에 따라 아이디어 기획으로 전환한다.

**제목:** 연구지원 공개데이터와 연구데이터 카탈로그를 잇는 근거 탐색 웹서비스

**필수 기관 데이터:** 한국연구재단 공개데이터를 1차 대상으로 삼고, 연구개발특구진흥재단 데이터는 대전 연구생태계 연결성 분석에 필요한 범위에서만 추가한다. 실제 필드·라이선스·갱신주기는 데이터 신청 뒤 확정한다.

**공통 엔진:** DataON/AIDA 출품과 같은 엄격한 출처·권리·품질 카드 엔진을 재사용한다.

**분리되는 출품물:** 이 공모전은 대전·세종 연구자에게 “어떤 지원사업과 공개 연구데이터가 연결되는가”를 보여주는 지역 연구지원 탐색에 집중한다. DataON/AIDA 출품의 일반 연구데이터 재사용 문제·평가셋·보고서를 그대로 제출하지 않는다.

## 하드 게이트

- [ ] 대전·세종 대학(원)생 1~4인 자격 증빙

- [ ] 타 공모전과 중복 수상·유사 출품 위험 검토
