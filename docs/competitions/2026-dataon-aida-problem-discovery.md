# 2026 DATA·AI 분석 경진대회 준비안

**상태:** 문제발굴 출품안 작성 중. 2026년 공식 포스터는 창업자가 2026-08-12 제공했으며, 접수 플랫폼의 최종 양식과 공개 조건은 제출 전에 주관기관에 재확인한다.

## 제안 문제

**제목:** 연구데이터를 찾은 뒤에도 쓸 수 없는 문제 — 출처·권리·품질을 함께 설명하고 기권하는 연구근거 큐레이션 에이전트

연구자는 검색 결과를 얻어도 다음을 다시 수작업으로 확인한다.

- 데이터와 모델의 영구 식별자와 실제 제공자
- 비영리·출처표기·재배포·2차 가공 조건
- 표본, 언어, 지역, 기간과 적용 범위
- 자동 주석·검증 방식·알려진 오류
- 공개 메타데이터와 실제 원문 사용 권한의 차이

이 확인이 누락되면 연구 재현성이 떨어지고, 권리 위반이나 부적절한 의료적 해석으로 이어질 수 있다. 검색 성능만 높이는 대신 “지금 써도 되는가”를 근거와 함께 판단하고 불충분하면 기권하는 에이전트를 만든다.

## DataON 가점 전략

- DataON 검색·상세 메타데이터를 중심 데이터 축으로 사용한다.
- AIDA의 생명과학 전문용어, 감염병 사건, 생물의학 언어모델 메타데이터와 결합한다.
- 한국연구재단 공개 연구지원 데이터는 별도의 출처·라이선스 검토 후 “어떤 연구가 어떤 데이터에 연결되는가”를 설명하는 외부 도메인으로만 결합한다.
- 개인 건강정보, 병원 진료기록, 비공개 논문 원문은 사용하지 않는다.

## 현재 산출물

- `/research-data` 한국어 시제품
- 엄격한 입력·결과·권리판단 스키마
- 공개 메타데이터 오프라인 스냅샷
- API 키 없이 재현되는 테스트
- 아래 실험계획의 Material Passport

## 일정

| 단계 | 포스터 일정 | 내부 완료 기준 |
|---|---:|---|
| 문제발굴 접수 | 2026-08-11 ~ 2026-09-04 | 문제정의, 데이터 적합성, 권리대장, 시제품 링크, 3분 설명 |
| 채택 문제 공개 | 2026-09-15 | 주최자 피드백을 별도 변경기록으로 반영 |
| 문제해결 | 2026-09-15 ~ 2026-11-06 | 고정 평가셋, 기준선, 기권 정확도, 재현 패키지 |
| 후보 선정 | 2026-11-09 ~ 2026-11-13 | 재실행 로그와 라이선스 증빙 |
| 발표·시상 | 2026-11-25 | 데모는 공개·합성 데이터만 사용 |
