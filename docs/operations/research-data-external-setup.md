# 연구데이터 외부 준비 목록

창업자가 나중에 계정과 키를 한 번에 준비할 때 사용하는 목록이다. 값 자체는 이 파일, GitHub, 채팅, 스크린샷에 기록하지 않는다.

## DataON

- [ ] DataON 기관·개인 계정 자격 확인
- [ ] 연구데이터 검색 API 이용신청
- [ ] 연구데이터 메타정보 상세조회 API 이용신청
- [ ] 허용할 고정 서버 egress IP 제출
- [ ] 승인번호, 약관 버전, 담당자, 할당량, 만료일 기록
- [ ] 키를 환경별 AWS Secrets Manager에 저장
- [ ] `DATAON_OPENAPI_KEY`가 가리키는 ARN과 정확한 VersionId만 보호된 환경에 등록
- [ ] 서버 사이드 검색·상세조회 외의 작업이 거부되는지 확인

## AIDA

- [ ] AIDA 계정 생성 및 OpenAPI 신청
- [ ] 데이터셋 검색·상세조회 권한 확인
- [ ] 사용할 각 데이터셋의 활용신청과 라이선스 승인
- [ ] 원문 파일 다운로드는 별도 승인 전 비활성화 유지
- [ ] 키를 환경별 AWS Secrets Manager에 저장
- [ ] `AIDA_OPENAPI_KEY`가 가리키는 ARN과 정확한 VersionId만 보호된 환경에 등록
- [ ] 호출량 제한, 오류 응답, 키 회전, 차단 연락처 기록

## 대전 공모전 지정 데이터

- [ ] 실제 참가팀의 대전·세종 대학(원)생 자격 서류
- [ ] 한국연구재단 공공데이터 목록·신청·라이선스 확인
- [ ] 연구개발특구진흥재단 데이터가 필요하면 별도 신청
- [ ] 데이터 출처문구, 갱신일, 필드 정의, 원문 URL 고정
- [ ] DataON/AIDA 외부 데이터 결합이 제출 규정상 허용되는지 운영사무국에 문의

## 경진대회 운영 확인

- [ ] DataON/AIDA 2026 접수 URL과 제출양식
- [ ] 문제발굴 개인·기관, 문제해결 개인·팀 자격의 정확한 적용
- [ ] 수상작 공개 시 코드·모델·문서·데이터 각각의 공개 범위
- [ ] 두 공모전 간 유사 출품 또는 중복 수상 제한
- [ ] 창업자 법인 명의와 개인·팀 명의 중 허용되는 제출 주체

## 절대 준비하지 않을 것

- 실제 환자 기록 또는 건강검진 결과
- 개인 명의의 공용 API 키를 브라우저에 넣는 방식
- 약관을 우회하는 크롤러
- 라이선스가 불명확한 모델 가중치나 데이터 파일의 Git 커밋
- `kisti-mcp` 등 연구용 도구를 공급망·라이선스 검토 없이 프로덕션 의존성으로 추가하는 일
