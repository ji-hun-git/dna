# 연구근거 에이전트

## 제품 결정

`연구근거 에이전트`는 사용자의 건강을 진단하거나 치료를 추천하는 의료 AI가 아니다. 공개 연구데이터를 찾은 뒤 그 자료를 실제 연구 시제품에 사용할 수 있는지 판단하기 위한 내부·공모전용 큐레이션 도구다.

첫 공개 화면은 별도 애플리케이션 `@gc/research-web`의 `/`다. 건강 제품의 `/research-data` 경로에서는 더 이상 제공하지 않는다. 현재 화면은 2026-08-12에 확인한 AIDA와 DataON의 공개 메타데이터 스냅샷만 읽으며 외부 API를 호출하지 않는다.

## 이 에이전트가 하는 일

1. 사용자가 세 개의 비개인 연구 주제 중 하나를 선택한다.
2. 에이전트가 주제 적합성, DOI 또는 공식 URL, 권리 상태를 기준으로 공개 자원을 정렬한다.
3. 각 결과에 출처, 형식, 확인일, 사용 제한, 품질 경고를 붙인다.
4. 재배포 금지 자료는 메타데이터만 표시한다.
5. 라이선스가 공개 페이지에서 확정되지 않으면 원문 다운로드와 학습을 차단한다.

## 하지 않는 일

- 증상, 검사 수치, 이름, 연락처, 주민등록번호, 진료기록을 입력받지 않는다.
- 질병 확률, 진단명, 치료법, 복약, 의료기관 순위를 반환하지 않는다.
- AIDA 또는 DataON 원문 데이터와 모델 가중치를 저장소에 복사하지 않는다.
- API 키가 없을 때 임의 웹 스크래핑으로 우회하지 않는다.
- `MediBioDeBERTa`를 한국어 임상 진단 모델로 표현하지 않는다.

## 외부 연결 경계

`apps/research-web/lib/research-data/connectors.ts`는 두 연결을 기본 비활성화한다. 활성화에는 약관 검토일, 권리대장 ID, AWS Secrets Manager의 정확한 VersionId, 서버 전용 호출, 차단 스위치, 개인데이터·파일다운로드 금지가 모두 필요하다. 브라우저 번들에 API 키를 넣지 않는다. 연구 앱 빌드는 건강 DB·세션·격리·감사·오브젝트 스토리지 자격증명을 발견하면 실패한다.
